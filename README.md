# Basketball Scoreboard

A simple and interactive basketball scoreboard web application built using HTML, CSS and JavaScript. This project was created while learning core frontend fundamentals.

---

## Built with

- HTML
- CSS
- Javascript (Vanilla)
- Netlify

---

## Features

- Interactive score tracking for two teams
- Buttons to add points (e.g., +1, +2, +3)
- Live score updates using JavaScript DOM manipulation
- Responsive layout using CSS Flexbox
- Lightweight and static

---

**What I learned in this section:**

- Connecting UI controls to JavaScript logic
- Updating the DOM dynamically in response to user actions
- Using addEventListener() for interactive behavior
- Structuring CSS for consistent layout with Flexbox
- Deploying a static project to Netlify
